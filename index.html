How do I export my library?

Spotify

  1. Exportify: log in, find Liked Songs, click Export. You get a CSV with ISRC codes.
  2. Or TuneMyMusic: source Spotify, destination File, format CSV.
  3. Or request your data at Spotify → Privacy settings and import YourLibrary.json.

Tidal, Apple Music, Deezer, Amazon Music

  1. TuneMyMusic or Soundiiz: pick the service as source, choose Favorites or Liked tracks, export to a CSV file.
  2. Apple Music on a Mac: Music app → File → Library → Export Library gives Library.xml, which also works.

YouTube Music

  1. Google Takeout: select only YouTube and YouTube Music, then import music-library-songs.csv.
  2. Or TuneMyMusic / Soundiiz as above.

Anything else

  • Any CSV or TSV with columns for Title, Artist and ideally Album. Column names are detected automatically.
  • A plain text file with one Artist - Title per line.
  • Several files can be combined: import one, then use Add another file.

Release years from ISRC codes

The year encoded in the ISRC is usually the release year, sometimes a re-registration. Years before 2005 are grouped in the first bar.

ISRC registrant

QZ, QM, QT, TC and GX are distributor prefixes (DistroKid, TuneCore and others) rather than countries. These are independent releases, which rarely get a vinyl pressing.

Library makeup

Matches are found by artist and album name, so a short or common title can occasionally pick up the wrong release. Every match links to its Discogs page; use Not a match to dismiss a wrong one and Recheck to search again.
