# SpotiVinyl

Статическая страница, которая показывает, какие из залайканных треков Spotify выходили на виниле. Источник данных о виниле: [Discogs API](https://www.discogs.com/developers).

## Как пользоваться

1. Откройте `index.html` в браузере (двойной клик по файлу достаточно, сервер не нужен).
2. Получите бесплатный токен на <https://www.discogs.com/settings/developers> («Generate new token»), вставьте в поле и нажмите «Сохранить». Токен хранится только в `localStorage` вашего браузера.
3. Нажмите «Начать проверку». Страница по очереди ищет каждый альбом или сингл в Discogs с фильтром `format=Vinyl`. Если по названию альбома ничего нет, делается второй запрос по названию трека.
4. Результаты сохраняются в браузере после каждого альбома. Вкладку можно закрыть и продолжить позже кнопкой «Продолжить проверку».

Discogs разрешает 60 запросов в минуту, поэтому библиотека из ~3000 альбомов проверяется примерно за час-полтора. Порядок проверки можно выбрать: сначала исполнители с наибольшим числом лайков, в порядке библиотеки или только то, что сейчас отфильтровано в списке.

## Файлы

- `index.html` — вся страница: разметка, стили и логика.
- `library.js` — библиотека треков, сгенерированная из экспорта Spotify (`Track name, Artist name, Album, ISRC, Spotify id`). Другой экспорт можно загрузить прямо на странице кнопкой «Загрузить другой CSV»; он тоже сохраняется в браузере.

Чтобы пересобрать `library.js` из нового CSV:

```bash
python3 - <<'EOF'
import csv, json
rows = list(csv.DictReader(open('My Spotify Library.csv', encoding='utf-8-sig')))
out = [[r['Track name'], r['Artist name'], r['Album'], r['ISRC'], r['Spotify - id']] for r in rows]
open('library.js', 'w', encoding='utf-8').write('window.SPOTIFY_LIBRARY = ' + json.dumps(out, ensure_ascii=False, separators=(',', ':')) + ';\n')
EOF
```

## Ограничения

- Сопоставление идёт по названию исполнителя и альбома, поэтому возможны ложные совпадения у коротких или распространённых названий. Рядом с каждым результатом есть ссылка на релиз в Discogs для проверки.
- «Не найдено» означает, что в Discogs нет винилового издания с таким исполнителем и названием. У независимых релизов через DistroKid или TuneCore (ISRC с префиксами QZ, QM, QT, TC) это обычный случай.
